next-steps-all

A Claude Code mod in bartester1/claude-mods

Derived from next-steps 1.0.0 (Thariq Shihipar, MIT). Adds 9 = all: puts every suggestion into the prompt box as one numbered draft, still never submitted. 1/2/3 and 0 work as before.
